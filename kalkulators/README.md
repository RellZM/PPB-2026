# Kalkulators

Aplikasi kalkulator Android sederhana menggunakan Kotlin dan Jetpack Compose.

## Fitur

- Mode input dua angka untuk operasi tambah, kurang, kali, bagi, dan modulus.
- Mode keypad lengkap dengan riwayat operasi.
- Validasi input dan penanganan pembagian dengan nol.

## Menjalankan Project

Buka project di Android Studio, lalu jalankan konfigurasi `app` pada emulator atau perangkat Android dengan minimum SDK 24.

Atau gunakan perintah berikut:

```bash
./gradlew assembleDebug
```
