# Login App

Aplikasi Android sederhana untuk menampilkan halaman login menggunakan Jetpack Compose.

## Fitur

- Input email dan password
- Tampilkan atau sembunyikan password
- Tombol login dan registrasi
- Tombol login dengan X dan Instagram
- Tampilan menggunakan Material 3

## Teknologi

- Kotlin
- Jetpack Compose
- Material 3
- Gradle

## Menjalankan Project

1. Buka project di Android Studio.
2. Tunggu proses Gradle selesai.
3. Jalankan aplikasi pada emulator atau perangkat Android.

Atau gunakan perintah berikut:

```bash
./gradlew assembleDebug
```

## Catatan

Fitur login, registrasi, dan login dengan X belum terhubung ke backend. Tombol Instagram saat ini membuka profil Instagram terkait.
